JevはTypeSafe AIが2026年9月に発表したAIモデルです。

簡単に説明すると、Jevは今までのAIのように文章を生成するのではなく、「判断」のみをJSON形式で出力するAIモデルです。

![Jevの仕組み](/images/jev.svg)

## 実践
まずは公式のPlaygroundでJevを試してみます。

![Jev Playground](/images/jev-playground.png)

入力は2種類あります。

### State

そのまま状態の意味を表します。
例えば、ユーザーの現在の状態やアプリケーションの状態などを表します。

### Questions

ユーザーからの質問や要求を表します。
質問形式は`Noul` `Choice` `Score`の3種類があります。

- `Noul`: はい・いいえの判断に向いてます。
- `Choice`: 選択肢から選ぶような判断に向いてます。
- `Score`: どのくらいとかどの程度のような判断に向いてます。

### Example

実際にJevに入力する例を示します。

例えば、探しているものに対してどのコーナーに振り分けるべきかを判断する場合、Jevに入力する例は以下のようになります。

#### State

```json
{
  "example_state": "ユーザーは鉛筆を探している"
}
```

#### Questions

```json
{
  "example_questions": {
      "type": "choice",
      "instructions": "ユーザーが探しているものに基づいて適切なコーナーを選んでください。",
      "criteria" : {
        "option_a": "文房具",
        "option_b": "家電",
        "option_c": "食品",
        "option_d": "服"
      }
    }
}
```

結果は以下のようにJSON形式で返されました。

正解である「文房具」が選ばれました。

```json
{
  "answers": {
    "decision": {
      "type": "choice",
      "choice": "文房具",
      "probabilities": {
        "文房具": 1,
        "服": 0,
        "食品": 0,
        "家電": 0
      }
    }
  },
  "usage": {
    "inputTokens": 377,
    "outputTokens": 50,
    "totalTokens": 427
  },
  "rounding": {
    "probabilityDecimals": 2,
    "scoreDecimals": 2
  },
  "confidence": {
    "decision": 1
  },
  "warnings": []
}
```

試しに「鉛筆」を「卵」に変えると「食品」が選ばれました。

## 何がすごい

### 安い
2026/10/6時点の料金ですが、入力トークンは100万トークン辺り$0.042で出力に至っては無料となっています。

キャッチコピーとしてはLLMより最大193.6倍高速、444.6倍低コストとなっています。が、これは公式の比較結果に基づくものなので、ベストケース的な目安として捉えるべきです。

### プログラムで使いやすい

switchやif的な条件分岐をプログラム内で行う場合、JevのJSON形式の出力は非常に扱いやすくなります。
例えば、ユーザーの選択に応じて処理を分岐させる場合、JSONの`choice`フィールドを参照するだけで簡単に条件分岐が可能になります。

## ユースケース

ぱっと思いつくものでは以下のようなユースケースがありそうです。

- メールの受信トレイの自動分類
- 求人マッチ度の数値評価
- 問い合わせの担当者の自動振り分け
- 入力に個人情報が含まれているかの判定

## まとめ

Jevは文章生成ではなく判断をJSON形式で出力するAIモデルであり、プログラム内での条件分岐やユースケースに応じた自動処理に非常に適していると考えられます。
発表から３週間ほどですが、すでに同様のAIモデル（CloudflareのClefやOSSのJev互換モデルなど）が登場しているので、どれが主流になるかはまだ不明です。

## 理解度チェック（AI生成）

以下の4択問題で、Jevの理解度をチェックしてみましょう。答えは折りたたまれているので、クリックして確認してください。

**Q1. Jevの特徴として正しいものはどれか？**
1. 自然な文章を生成することに特化している
2. 「判断」のみをJSON形式で出力する
3. 画像を入力して説明文を生成する
4. プログラムのソースコードを自動生成する

> [!success]- 答えを見る
> **正解: 2. 「判断」のみをJSON形式で出力する**
> Jevは今までのAIのように文章を生成するのではなく、判断結果だけをJSON形式で返すAIモデルです。

**Q2. Jevへの入力として本文で挙げられている2種類の組み合わせはどれか？**
1. PromptとContext
2. StateとQuestions
3. InputとOutput
4. SystemとUser

> [!success]- 答えを見る
> **正解: 2. StateとQuestions**
> Stateはユーザーやアプリケーションの現在の状態を、Questionsは判断してほしい質問や要求を表します。

**Q3. 「求人とのマッチ度を数値で評価したい」場合に最も適した質問形式はどれか？**
1. `Noul`
2. `Choice`
3. `Score`
4. `Text`

> [!success]- 答えを見る
> **正解: 3. `Score`**
> `Score`は「どのくらい」「どの程度」のような判断に向いています。`Noul`ははい・いいえ、`Choice`は選択肢から選ぶ判断に向いており、`Text`という形式はありません。
